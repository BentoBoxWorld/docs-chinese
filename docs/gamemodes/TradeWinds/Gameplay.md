# 🧭 水手手册

玩家在前几周在海上发现的一切，都集中在一个地方——以及管理员需要知道的关于各个部分如何相互联系的一切。TradeWinds 是一个规则简单但后果深远的游戏；规则如下，后果由你的玩家决定。

## ⛵ 你的第一个小时

你到达**出生港**，带着一艘初始橡木船——3 个货物格、燃料槽里已有煤炭——和一个值得重复的建议：*船是你的货舱和你的生计；保持它的接近。*

1. **右键点击你的船** 打开货舱。货物和燃料存放在这里——永远不要放在你的口袋里。在任何市场交易会直接在货舱中进出商品。
2. **与广场上的商人交谈**。每个岛屿都张贴买卖价格；差额就是游戏。
3. **启航** 从岛屿划走。当你走得足够远时，你可以选择传送或继续划行。穿过一个新岛屿的水域**探图**会将其永久标记在你的地图上，并在航海家阶梯上增加一小步。
4. **高价出售。** 恭喜：你是一个商人。这个手册中的其他一切都是关于更快、更大地做这件事，以及更接近边缘。

## 🚢 一艘船，二十个船体

你的船是你唯一的货舱，你恰好只有一艘。它的船体决定了你的货物格数：

| | | |
|---|---|---|
| 竹筏：2 | 橡木船：3 | 云杉船：4 |
| 竹箱筏：5 | 桦木船：6 | 橡木箱船：7 |
| 丛林船：8 | 云杉箱船：9 | 相思船：10 |
| 桦箱船：11 | 深色橡木船：12 | 丛林箱船：13 |
| 红树船：14 | 相思箱船：15 | 樱花船：16 |
| 深色橡木箱船：17 | 淡橡木船：18 | 红树箱船：19 |
| 樱花箱船：20 | 淡橡木箱船：21 | |

- **造船厂商出售** 岛屿科技等级能建造的每个船体，除了你已经航行的尺寸。把你的船带到码头并买更大的：那是一次**以旧换新**：相同的货舱、相同的货物、更多的格数，你下面的船体（或在你的包里，或停靠在码头）明显变成了新类型。用你在远处海洋的船买它就是一次**彻底购买**：新船到手，旧的留在**无主**状态无论在哪里，船上有货物，先到先得。对话会在你的金钱移动前警告你。
- **船可以被夺取。** 登上或拿起一艘不属于你的船体，你会被问：拿走船（放弃你的船在那里）、只拿货物（仅当你自己的船足够接近来装载——货物永远不会传送）或离开。一个属于某人的船停在合法岛屿的保护内是不可触及的；同一艘船停在无政府水域中就不行了。
- **死亡不是末尾。** 你的船浮在你离开它的地方，仍然是你的，海图会标记它。如果你*携带*它，失事现场会被标记。无船重生时港口会借你一艘筏进行回程划行。
- **岩浆是唯一真正的摧毁者。** 其他一切只是改变谁在拿着船体。
- **端游是扩展器。** 顶级港口出售货物扩展器，将货舱扩展到阶梯之外——按安装单位价格翻倍。钱包是唯一的上限。

## 🏝️ 阅读海洋

每个贸易岛屿都有一个**类型**（它种植、挖掘或建造什么——因此它便宜出售和昂贵购买什么）、一个**科技等级**（其造船厂能建造什么及其装备库存什么）和一个**安全等级**：

| 等级 | 水域 | 规则 |
|------|------|------|
| **安全** | 出生点周围 | 被巡逻、陆地上无敌对生成、海关眼尖 |
| **有警力** | 贸易路线 | 有法律、走私风险大、守卫者白天巡逻 |
| **前沿** | 长路线 | 法律稀薄、收益更好、陪伴更糟糕 |
| **无政府** | 边缘 | 根本没有法律——走私金币、海盗船队和其他玩家 |

价格遵循地理：离安全越远，交易越好——在法律的两边。每次购买和销售也**漂移本地价格**，所以一条路线可能被耗尽，一个被忽视的港口可能悄悄成为金矿。

## 🗺️ 四处走动

**划船**是免费的并探图你经过的一切。**传送**发生在岛屿边界——驶入可见的幕墙，对话会提供每个已探图目的地及其燃料价格（大约每 100 块 1 燃料单位）。燃料是任何燃烧的东西，价值合理：原木 1、海草块 4、煤和木炭 8、烈焰棒 12、煤块 80、熔岩桶 100——都在货舱燃料行中携带，占用货物空间。那个权衡是玩家必须做的。

- `/tw chart` 提起**全息指南针**：已探图的岛屿、码头方向、你的船，以及——如果你拥有一个——家。
- `/tw starchart` 将你探过的世界绘制到一个**地图物品**上，你可以拿出来放回去。
- `/tw rank` 显示你的航海家等级和前十名水手按岛屿已探。

!!! danger "传送误差"
    每次传送都有一个小机会（默认 5%）将你扔进**间隙地**——一片黑暗的地狱海洋，烧焦的天空。重新启动到你的原始目的地的传送**永远免费**……但间隙地是唯一在灵魂沙滩上长疣木、烈焰兵营其乌鸦巢、凋灵瞭望塔守卫值得绕道掠夺品的地方。一开始的意外变成了目的地。TradeWinds 中没有地狱门户——海有它自己的方式进入，陆地上的传说书解释为什么门户拒绝点燃。

## 🎖️ 等级和阶梯

绘制岛屿是游戏的里程表，19 个航海家等级标记距离——**水手**在开始；**湾区探险家**在 10；**海图制作者**在 20；**潮汐船长**在 36，声称解锁；**咸狗上将**在 56；一直到**神话航海家**在 100。`/tw rank` 前十和 `%tradewinds_rank%` / `%tradewinds_top_name_1%` 占位符为服务器提供现成的排行榜文化。管理员可以用 `/twadmin rank` 晋升、降级或重置。

## 🏠 你自己的岛屿

散落在贸易岛屿之间是**野生小岛**——小的、无主的、可声称的：

- **门槛：** 站在小岛上，持有**潮汐船长**等级，并支付价格（默认**$150,000**——故意高于顶级船，因为船体阶梯优先）。先到先得。
- **你得到什么：** BentoBox 保护，配标准标志 GUI、一个团队、岛屿周围的 `/tw sethome` 和 `/tw home`，以及 `/tw go` 在你站在你的岛屿上时踩步你的家。如果安装了 Bank 附属，你的岛屿自动获得一个账户。
- **跨海回家：** 你的声称变成每个边界对话中的**仅限成员的传送节点**。更喜欢航行？`/tw go` 在海上设定**返航**：白天一个粗略指南针方向，夜间——当星星出现时——精确距离和进度。教孩子们用夜空导航；它有效。
- **团队成员不需要等级。** 只有声称者通过门槛；潮汐船长可以带整个船队回家。
- **取消声称故意伤害。** 仅所有者、团队必须先清空，没有退款——一切都完全如同被留下的那样，回到野生等待下一个船长。

## 🚨 法律和无法律

犯罪层（配置中的一个主开关）是将地图的地理变成故事的东西：

- **声誉** 从诚实到**逃犯**。海关在合法港口扫描货舱中的走私品；被抓够多次，安全市场就会对你关门。
- **走私品**（糖，可配置）在合法的地方毫无价值，在没人问问题的地方则无价。扫描风险——而不是价格——是走私的成本。
- **罚款** (`/tw fine`) 在任何仍然会和你说话的港口购买一份干净的记录。
- **赏金** 在通缉玩家身上可以被任何人合法地在逃犯被迫交易的水域收取。警察暴民在合法岛屿强制和平——永远不会掉落战利品，所以没有什么可以种植。

设计是故意的：犯罪支付，它支付你*进入危险*。最富有的走私贩最终在海盗船队和赏金猎人已经的地方交易。

## 🌊 在海上发现你的东西

开放水域滚动遭遇，按与码头的距离和你所在的等级来调整：

| 遭遇 | 水域 | 何时 |
|------|------|------|
| 🐡 河豚群 | 安全–有警力 | 任何时间——一个刺痛，不是伏击，永远不值得种植 |
| 🔱 守卫者巡逻 | 有警力+ | 白天 |
| 🧟 溺水掠夺者 | 有警力+ | 晚上——有些携带三叉戟 |
| 👻 幻影飞行 | 前沿+ | 晚上，在桅杆上方 |
| 🦑 深渊恐怖 | 前沿+ | 在龙骨下方 |
| 🏴‍☠️ 海盗船队 | 无政府 | 船舶，他们从甲板上战斗 |
| 🧪 海女巫 | 无政府 | 船舶，保持她的距离 |

遭遇击杀支付**战利品**——海关盖章的掠夺品直接进入货舱，海本身支付的唯一金钱。每个名单、包大小和机会都在配置中的 `encounters` 中。

## 🛠️ 对掌舵的管理员

- **种子就是世界。** 用数据库备份 `config.yml`；`ocean.seed` *是* 你的世界。如果你想让玩家在 Discord 上理论化路线就发布它，如果你想要探险家就保密它。
- **船只日志** (`boats.logbook`，默认开启）为每个船舶生命周期事件——放置、拆解、夺取、购买、沉没及其水手——用坐标写一行控制台。当玩家问*"我的船去哪儿了？"*时，答案就在日志中。
- **`/twadmin boat <player>`** 直接从数据库读取他们的船舶记录：货物、燃料、最后看见位置，以及船体是否实际上漂浮在那里、在某人的包中，或坐在一个未加载的块中。`restore` 重新生成一艘真正丢失的船，货物完整——在真实船体被加载时它会拒绝，所以它不能用于复制。
- **`/twadmin islands` / `tpisland`** 用于游览，**`customs`** 查看任何地点的法律观点，**`priceaudit`** 验证每种货物有价格，以及**`warpfail`** 按需测试间隙地。
- **遗弃船清理**：遗弃的船*物品*（及其货物记录）在可配置的 TTL 后过期。船*实体*永远不会过期——一艘遗弃的船保持世界的一部分，直到有人拿走它。
