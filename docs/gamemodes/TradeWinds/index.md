# 🌬️ TradeWinds

由 [tastybento](https://github.com/tastybento) 创建和维护。

**TradeWinds** 是一个用于 BentoBox 的海上贸易游戏模式：一片无尽的、程序生成的海洋，散落着众多 NPC 贸易岛屿。你的玩家们一开始一无所有，只有一艘划艇和一口袋煤炭——而这艘船**就是**他们的货舱。在农业岛低价购买，在工业港口高价出售，看着金钱滚滚而来……或者抄近路走私、赏金猎人和海盗的道路，然后承担相应的后果。

如果你曾经在 *Elite* 或 *TradeWars 2002* 上浪费过一个周末，这就是那种感觉，在 Minecraft 中重新打造。如果你没有——你的玩家们即将发现为什么你会沉迷于此。

## 🧭 为什么玩家们着迷

- 🏝️ **无尽的随机海洋世界。** 每个岛屿的位置、类型、科技等级、安全等级、生物群系和名称都来自于一个种子数。玩家可以探索并发现新位置。使用默认种子或选择一个新种子来拥有独特的世界。分享你的种子，另一个服务器就能获得完全相同的贸易海洋。
- ⛵ **船就是货舱。** 货物存放在船上，船可以通过 **20 个船体等级**（竹筏 → 淡橡木箱船）升级，失去船舰**意味着什么**。一个玩家，一艘船——每个船体决定都重要。
- 📈 **值得研究的市场。** 八种岛屿个性（农场、矿山、渔场、森林、工业、奢侈品、冷港口……）各有各的买卖方式，每笔交易都会推动本地价格。好的贸易路线是被**发现**的，而不是被发布的。
- ⚡ **两种旅行方式，都很公平。** 划船是免费的、缓慢的，让你通过无法区域，但可能获得丰厚回报。传送是瞬间的，但会消耗货舱中的燃料——而 5% 的传送误差会把你扔进**间隙地**，一片充满敌意的地狱海洋，那里有疣木、烈焰棒和凋灵瞭望塔。两种方式都不会绝对击败另一种；这种张力就是游戏本身。
- 🗺️ **海图、星星和等级。** 提升海图会浮起一个全息指南针，显示你探过的所有地方。每个被玩家探过的岛屿都会推进**航海家阶梯**——从水手到神话航海家的 19 个等级，内置前十排行榜和计分板占位符。
- 🏠 **自己赚来的岛屿。** 达到**潮汐船长**（36 个岛屿已探）并携带大量资金，任何你找到的野生小岛都可以成为你的：保护、团队、家点、仅限成员的传送节点以及通过星星导航的夜间回家。先到先得。
- 🚨 **能让你陷入危险的犯罪利益。** 走私品只在法律松散的地方出售；犯罪记录将你锁在安全市场之外，并在你的头上放置一个其他玩家可以合法收取的赏金。最富有的走私贩们会被结构性地推向地图危险边缘——海盗们已经聚集的地方。
- 🐡 **一片会反击的海洋。** 白天守卫兵营、晚上溺水袭击者、幻影、深渊恐怖、船舶海盗船队、海女巫——随着水域的法律松懈而逐级升级。即使是安全航道也偶尔会有河豚群，只是为了让舵手保持清醒。

**难度就是地理。** 出生点附近的水域被巡逻和平静——新玩家和较年轻的玩家可以和平交易。危险、走私和 PvP 赏金空间都在**其他地方**，前往那里总是一个选择。这使得 TradeWinds 成为少数能同时在家庭服务器和无情竞争服务器上运作的经济游戏之一，配置相同。

## ⚓ 一次会话的感受

你从出生港口出海，有三格货物空间和一个直觉：往东两个岛屿的渔村是小麦价格的两倍。你划第一段——燃料就是金钱——一路上探过一个新小岛，朝潮汐船长又迈进一步。在边界幕墙处，传送对话提供 14 单位煤炭的过境费用；你接受了，因为太阳正在落山，溺水掠夺者统治着这里的夜晚。市场付清了，货舱重新装满了廉价鱼，在回程的海图上你注意到一个带红色标记、你从未敢访问的岛屿正在**愚蠢的**价格购买鱼。这只需要一次安静的航行……

那个循环——计划、航行、交易、冒略比上次更多风险——就是整个游戏，它不会放手。

## 🔧 设置

!!! warning "需要 Vault 和经济插件"
    所有交易都通过 Vault 进行。在首次启动前安装 Vault 加上任何 Vault 兼容的经济插件（EssentialsX Economy、CMI 等）。TradeWinds 本身格式化金钱——整数金币，无小数——使用其配置中的 `economy.currency-symbol`。如果你想要 BentoBox 的选项，使用开启货币的 InvSwitcher——它是 BentoBox 的一个经济。

1. **下载 TradeWinds 附属** 并将其放在 `/plugins/BentoBox/addons/`
2. **启动服务器**——`tradewinds_world`（海洋）和 `tradewinds_world_nether`（间隙地）自动生成。故意**没有末地世界**。
3. **以 Op 身份登录并四处看看**：`/twadmin islands` 列出最近的贸易岛屿，`/twadmin tpisland <#>` 传送你到一个。
4. **选择你的世界种子** *（可选，玩家加入前）*：在 `config.yml` 中设置 `ocean.seed`。每个岛屿位置、类型和名称都源于这个单一数字——之后改变它就是一个不同的海洋。
5. **根据品味调整经济** *（可选）*：价格、船只成本、传送燃料费率、犯罪和遭遇表都在 `config.yml` 中，预期默认值已经就位。

!!! tip "推荐的伴侣"
    - **InvSwitcher**——将库存、生命和饥荒与其他游戏模式分开。包括一个经济。
    - **Bank**——声称的玩家岛屿如果安装了 Bank 附属会自动附加到 Bank。允许团队成员之间的资金汇集。

## 🎮 指令

玩家指令是 `/tw`（或 `/tradewinds`）；管理员指令是 `/twadmin`。赤裸的 `/tw` 启航——它是通往海洋的大门，也是游戏唯一的小心传送：它将你返回到你离开的水域，如果你站在你自己的岛屿上会踩步你的家点，在其他任何地方的海上它会告诉你**方向和距离**回家，而不是给你一次骑行。TradeWinds 中没有什么会传送货物。

完整的指令参考在 [这里](Commands.md)。

## ⚙️ 配置

一切与游戏相关的都在 `config.yml` 中，分阶段介绍，带有注释解释*为什么*每个默认值就是这样。每个管理员在启动前都应该看一眼的一个设置：

```yaml
ocean:
  # 海洋种子。每个岛屿的位置、类型、安全等级、生物群系、名称和
  # 路线成本都是确定性地从这个单一数字派生的——分享它，另一个
  # 服务器会获得相同的贸易海洋。0 表示：使用世界种子。
  seed: 20260729
```

其他值得浏览的部分：`boats`（船体阶梯和价格）、`travel.warp`（燃料成本和传送误差机会）、`ranks`（航海家阶梯）、`claims`（玩家岛屿的价格）、`crime`（整个法律层有一个主开关）和 `encounters`。
